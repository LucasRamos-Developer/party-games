# Imagens dos filmes (opcional)

O jogo já funciona só com as pistas em texto de `filmes.js`. Para usar
imagens no lugar das pistas:

1. Crie uma pasta com o `id` do filme, por exemplo `frames/rei-leao/`.
2. Coloque até 5 imagens, da mais difícil para a mais fácil
   (`1.jpg`, `2.jpg`, … `5.jpg`).
3. Em `filmes.js`, adicione ao filme: `frames: ['1.jpg', '2.jpg', '3.jpg', '4.jpg', '5.jpg']`.

Etapas sem imagem continuam mostrando a pista em texto.

Atenção: este repositório e o GitHub Pages são públicos, então tudo o que
for colocado aqui fica acessível na internet. Use só imagens que você tem
direito de publicar.
