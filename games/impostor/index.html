Impostor

Como jogar

  1. Todos recebem a mesma palavra secreta, menos o impostor (2 impostores com 7 ou mais jogadores).
  2. O impostor só sabe a categoria. Na ordem, cada um diz uma palavra ligada à secreta.
  3. Depois de conversar, todos votam em quem acham que é o impostor.
  4. Pegou o impostor: +1 para cada um dos outros. Ele escapou: +2 para cada impostor.
