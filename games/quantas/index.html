    Como jogar

    1. O app sorteia um confronto: um jogador de cada uma das duas equipes.
    2. Aparece uma pergunta, como Frutas ou Países que começam com B.
    3. Leilão: as equipes se alternam dando lances (“meu jogador fala 6!”). Cada vez tem um tempo; se ele acabar, quem estava decidindo responde. Quem passar deixa o último lance para o adversário.
    4. Quem ganhou o leilão tem o tempo do relógio para falar a quantidade prometida. O outro time confere.
    5. Cumpriu a meta: +1 ponto. Não cumpriu: +1 para o adversário. Quando todos tiverem jogado, vence quem tiver mais pontos.
