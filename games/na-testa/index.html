    Como jogar

    1. Um jogador segura o aparelho na testa, com a tela virada para a equipe, sem olhar.
    2. A equipe dá dicas (ou faz mímica, na categoria Ações) para ele adivinhar.
    3. Acertou: toque no botão verde ✓ Acertou (ou incline a tela para baixo). Não sabe: botão ✗ Passou (ou incline para cima).
    4. Cada acerto vale 1 ponto. Depois das rodadas, vence quem tiver mais pontos.
